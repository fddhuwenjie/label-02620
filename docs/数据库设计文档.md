## 枚举类型定义

### UserRole - 用户角色
| 值 | 说明 |
|---|---|
| `admin` | 管理员 |
| `manager` | 经理 |
| `operator` | 操作员 |

### MaterialCategory - 物料类别
| 值 | 说明 |
|---|---|
| `fabric` | 面料 |
| `accessory` | 辅料 |
| `packaging` | 包装材料 |

### OrderStatus - 订单状态
| 值 | 说明 |
|---|---|
| `pending` | 待生产 |
| `in_progress` | 生产中 |
| `completed` | 已完成 |
| `cancelled` | 已取消 |

### ProcessName - 工序名称
| 值 | 说明 |
|---|---|
| `cutting` | 裁剪 |
| `sewing` | 缝制 |
| `ironing` | 熨烫 |
| `packaging` | 包装 |
| `quality_check` | 质检 |

## 1. 用户表 (users)

存储系统用户信息，包括管理员、经理和操作员。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `username` | VARCHAR(50) | NOT NULL, UNIQUE, INDEX | - | 用户名 |
| `hashed_password` | VARCHAR(255) | NOT NULL | - | 加密密码 |
| `full_name` | VARCHAR(100) | - | NULL | 姓名 |
| `role` | ENUM | - | `operator` | 角色 (admin/manager/operator) |
| `is_active` | BOOLEAN | - | TRUE | 是否启用 |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | - | CURRENT_TIMESTAMP | 更新时间 (自动更新) |

**索引：**
- `idx_username` (username)

**关联关系：**
- 一对多 → `production_records` (操作员记录)
- 一对多 → `material_usages` (物料使用记录)

## 2. 供应商表 (suppliers)

存储物料供应商信息。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `code` | VARCHAR(50) | NOT NULL, UNIQUE, INDEX | - | 供应商编码 |
| `name` | VARCHAR(200) | NOT NULL | - | 供应商名称 |
| `contact_person` | VARCHAR(100) | - | NULL | 联系人 |
| `phone` | VARCHAR(20) | - | NULL | 联系电话 |
| `address` | VARCHAR(500) | - | NULL | 地址 |
| `is_active` | BOOLEAN | - | TRUE | 是否启用 |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |

**索引：**
- `idx_code` (code)

**关联关系：**
- 一对多 → `materials` (供应的物料)

## 3. 物料表 (materials)

存储物料/原材料信息，包括面料、辅料和包装材料。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `code` | VARCHAR(50) | NOT NULL, UNIQUE, INDEX | - | 物料编码 |
| `name` | VARCHAR(200) | NOT NULL | - | 物料名称 |
| `category` | ENUM | NOT NULL | - | 物料类别 (fabric/accessory/packaging) |
| `unit` | VARCHAR(20) | - | `件` | 计量单位 |
| `specification` | VARCHAR(500) | - | NULL | 规格说明 |
| `color` | VARCHAR(50) | - | NULL | 颜色 |
| `supplier_id` | INT | FOREIGN KEY | NULL | 供应商ID |
| `stock_quantity` | FLOAT | - | 0 | 库存数量 |
| `min_stock` | FLOAT | - | 0 | 最低库存预警 |
| `price` | FLOAT | - | 0 | 单价 |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | - | CURRENT_TIMESTAMP | 更新时间 (自动更新) |

**索引：**
- `idx_code` (code)

**外键约束：**
- `supplier_id` → `suppliers.id` (ON DELETE SET NULL)

**关联关系：**
- 多对一 → `suppliers` (所属供应商)
- 一对多 → `material_usages` (使用记录)

---

## 4. 生产订单表 (production_orders)

存储生产订单信息。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `order_no` | VARCHAR(50) | NOT NULL, UNIQUE, INDEX | - | 订单编号 |
| `product_name` | VARCHAR(200) | NOT NULL | - | 产品名称 |
| `style_no` | VARCHAR(50) | - | NULL | 款号 |
| `quantity` | INT | NOT NULL | - | 订单数量 |
| `unit` | VARCHAR(20) | - | `件` | 单位 |
| `status` | ENUM | - | `pending` | 状态 (pending/in_progress/completed/cancelled) |
| `priority` | INT | - | 3 | 优先级 (1-5，1最高) |
| `deadline` | DATETIME | - | NULL | 交货日期 |
| `customer_name` | VARCHAR(200) | - | NULL | 客户名称 |
| `remarks` | TEXT | - | NULL | 备注 |
| `created_by` | INT | FOREIGN KEY | NULL | 创建人ID |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | - | CURRENT_TIMESTAMP | 更新时间 (自动更新) |

**索引：**
- `idx_order_no` (order_no)
- `idx_status` (status)

**外键约束：**
- `created_by` → `users.id` (ON DELETE SET NULL)

**关联关系：**
- 一对多 → `production_records` (生产记录)
- 一对多 → `material_usages` (物料使用记录)

---

## 5. 生产记录表 (production_records)

记录每个订单的生产进度，按工序跟踪。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `order_id` | INT | NOT NULL, FOREIGN KEY | - | 关联订单ID |
| `process_name` | ENUM | NOT NULL | - | 工序名称 (cutting/sewing/ironing/packaging/quality_check) |
| `quantity_completed` | INT | - | 0 | 完成数量 |
| `quantity_defective` | INT | - | 0 | 不良品数量 |
| `operator_id` | INT | FOREIGN KEY | NULL | 操作员ID |
| `work_station` | VARCHAR(50) | - | NULL | 工位 |
| `start_time` | DATETIME | - | NULL | 开始时间 |
| `end_time` | DATETIME | - | NULL | 结束时间 |
| `remarks` | TEXT | - | NULL | 备注 |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 记录时间 |

**索引：**
- `idx_order_id` (order_id)

**外键约束：**
- `order_id` → `production_orders.id` (ON DELETE CASCADE)
- `operator_id` → `users.id` (ON DELETE SET NULL)

**关联关系：**
- 多对一 → `production_orders` (所属订单)
- 多对一 → `users` (操作员)

---

## 6. 物料使用记录表 (material_usages)

记录生产过程中的物料消耗情况。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|-------|------|
| `id` | INT | PRIMARY KEY, AUTO_INCREMENT | - | 主键ID |
| `order_id` | INT | NOT NULL, FOREIGN KEY | - | 关联订单ID |
| `material_id` | INT | NOT NULL, FOREIGN KEY | - | 物料ID |
| `quantity_used` | FLOAT | NOT NULL | - | 使用数量 |
| `operator_id` | INT | FOREIGN KEY | NULL | 操作员ID |
| `usage_date` | DATETIME | - | CURRENT_TIMESTAMP | 使用日期 |
| `remarks` | TEXT | - | NULL | 备注 |
| `created_at` | DATETIME | - | CURRENT_TIMESTAMP | 记录时间 |

**索引：**
- `idx_order_id` (order_id)
- `idx_material_id` (material_id)

**外键约束：**
- `order_id` → `production_orders.id` (ON DELETE CASCADE)
- `material_id` → `materials.id` (ON DELETE CASCADE)
- `operator_id` → `users.id` (ON DELETE SET NULL)

**关联关系：**
- 多对一 → `production_orders` (所属订单)
- 多对一 → `materials` (使用的物料)
- 多对一 → `users` (操作员)

## 表关系图

```
┌─────────────┐
│   users     │
└──────┬──────┘
       │
       │ 1:N
       ▼
┌──────────────────┐     ┌─────────────────────┐
│ production_orders│◄────│  production_records │
└────────┬─────────┘     └─────────────────────┘
         │                         ▲
         │ 1:N                     │ N:1
         ▼                         │
┌──────────────────┐               │
│ material_usages  │───────────────┘
└────────┬─────────┘
         │
         │ N:1
         ▼
┌─────────────┐     ┌─────────────┐
│  materials  │◄────│  suppliers  │
└─────────────┘ N:1 └─────────────┘
```

**关系说明：**
- 一个用户可以创建多个生产订单
- 一个用户可以有多条生产记录和物料使用记录
- 一个供应商可以供应多种物料
- 一个生产订单可以有多条生产记录（不同工序）
- 一个生产订单可以有多条物料使用记录
- 一种物料可以被多个订单使用
